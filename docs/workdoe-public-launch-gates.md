# Workdoe Public Release Status

Reviewed November 11, 2026. **Controlled beta only; unrestricted commercial
launch is not yet accepted.** Publishing source or approving a technical
deployment does not approve policies, a wider cohort or a rollback.

## Release Boundaries

The release contains the current application, tests, reviewed dependencies
and public documentation. New internal audit material and signed-in screenshots
are excluded from this public export; previously published archives remain
historical. The complete current local review remains
preserved separately.

Local verification covers 739 Python tests, strict preflight, provenance,
security and build checks. An exported release must pass its own checks and
GitHub CI. These results are not a substitute for exact-release hosted or
owner-operated acceptance. Production deployment remains a separate action;
staging initialization and activation are not authorized by a source push.

Public photo uploads and optional marketplace email remain disabled in the
reviewed beta configuration. No payments, escrow, subscriptions, paid ranking
or instant booking are part of this release.

## Required Evidence

- Approve Terms, Privacy, Safety, regulated-service advisories, retention and
  deletion decisions. Policies remain drafts until a documented owner/legal
  decision and coordinated implementation are complete.
- Complete the coordinated account-data request/deletion process, recovery
  safeguards, reliable contact delivery and urgent incident coverage.
- Finish the compiled Clerk dependency/notice inventory, missing attribution
  and advisory dispositions. Workdoe is proprietary; pinned dependencies and
  retained notices are not blanket license or vulnerability clearance.
- Qualify isolated hosted staging, synthetic-only recovery and an approved
  security-compatible rollback target before broader rollout.
- Complete the exact hosted consumer/contractor journey, including project
  edits, bids, approval, private messaging, completion, moderation and private
  media permissions. Earlier tests are evidence for their own releases only.
- Finish physical iPhone/iPad Safari, keyboard/VoiceOver, zoom and rotation
  checks and performance measurements under an agreed test profile.
- Verify current production identity, HTTPS/security headers, routes, provider
  isolation, abuse controls and account-wide usage before deployment.

Neither zero PII, zero security risk, guaranteed free-tier costs nor
commercial readiness is asserted.

## Next Decision

Keep source publication, controlled-beta deployment, hosted staging work and
unrestricted launch approval separate. Do not enable uploads, optional mail,
paid services, change policies or apply migrations as a side effect of a push.

## Internal Records

New detailed audits, provider readbacks and account-specific QA captures are
retained locally and are not added by this public repository export.
Links redirected here identify review topics, not public access to the
underlying records. Current requirements, source, tests and explicit operating
decisions determine readiness; a screenshot or a green check alone does not.
